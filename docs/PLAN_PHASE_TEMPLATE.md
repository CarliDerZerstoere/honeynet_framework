# Phasen-Vorlage (Roadmap / Tickets)

Vorlage für P0–P4 oder Teilaufgaben; an Plan-Abschnitt I.2 angelehnt.

| Feld | Inhalt |
|------|--------|
| **Ziel** | Ein Satz: was nachher besser sein soll. |
| **In** | Voraussetzungen (Code-Version, Flags, Abhängigkeiten). |
| **Out** | Konkrete Artefakte (Dateien, APIs, Metriken). |
| **DoD** | Abnahmekriterien (Tests, manueller Schritt, Metrik). |
| **Owner** | Verantwortlich (Person/Team). |
| **Termin** | Zieltermin oder Sprint. |
| **Risiko** | Top-1-Risiko + Mitigation. |

**YAGNI-Hinweis:** Phasen als **P1 core** (Observability), **P2 internal-first** (Validator/Plugins), **P3/P4 enterprise-optional** (Judge, Catalog) kennzeichnen, wenn Scope gefährdet.
